16. Keyboard shortcuts

On a Mac, read Ctrl as ⌘. Every command, with its shortcut, is also in the command palette (F1).

Everywhere

Action Keys
Command palette F1, Ctrl+Shift+P
Go to a note in the folder Ctrl+P
Settings Ctrl+,
Sidebar on/off Ctrl+Shift+E
Split view Ctrl+\

The file shortcuts below (new, open, save, close, PDF) and switching tabs work everywhere too. The rest work while the cursor is in the editor.

View

Action Keys
Focus mode F8
Live preview / seamless view Ctrl+Alt+L / Ctrl+Alt+M
Word wrap Alt+Z
Present as slides F5
Graph of notes / beside the editor Ctrl+Shift+G / Ctrl+Alt+G
Board Ctrl+Alt+B
Terminal (desktop) Ctrl+`
Ask your notes (desktop) Ctrl+Shift+L

Files

Action Keys
New note Alt+N
Open file / folder Ctrl+O / Ctrl+Shift+O
Save / Save as / Save all Ctrl+S / Ctrl+Shift+S / Ctrl+Alt+S
Close tab Alt+W
Next / previous tab Alt+PgDn / Alt+PgUp
Export as PDF Ctrl+Alt+P
Rename / delete (in the file tree) F2 / Del

Writing

Action Keys
Bold / italic / inline code Ctrl+B / Ctrl+I / Ctrl+E
Strikethrough Ctrl+Shift+X
Heading 1–6 Ctrl+Alt+1 … 6
Bulleted / numbered / task list Ctrl+Shift+8 / 7 / 9
Tick a task Ctrl+Enter
Quote Ctrl+Shift+.
Link Ctrl+K
Code block Ctrl+Alt+C
Paste as plain text Ctrl+Shift+V
Find and replace / in the folder Ctrl+F / Ctrl+Shift+F
Undo / redo Ctrl+Z / Ctrl+Shift+Z
Fold / unfold a section Ctrl+Shift+[ / ] (Mac: ⌘⌥[ / ⌘⌥])
Move a section up / down Alt+Shift+↑ / ↓ (on its heading)
Next occurrence (another cursor) Ctrl+D
Cursor above / below Ctrl+Alt+↑ / ↓
Spelling suggestions for the word at the cursor Ctrl+.

Tables

Action Keys
Next / previous cell Tab / Shift+Tab
Cell below Enter
Move row / column Alt+↑ ↓ / Alt+← →
Line up columns Ctrl+Alt+F

Reviewing

Action Keys
Suggest mode on/off Ctrl+Alt+T
Add a comment Ctrl+Alt+N
Send a comment Ctrl+Enter
Rewrite with AI (desktop) Ctrl+Alt+R

Presenting

Action Keys
Next / previous slide → / ←, or click
Full screen F
Stop Esc
