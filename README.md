# Marky — downloads

Marky is a fast, safe Markdown editor with live preview, math, diagrams, folders and export to HTML, PDF and Word.

**Download:** see [Releases](https://github.com/michaelkloprogge-gif/marky-releases/releases/latest).

- `Marky_<version>_x64-setup.exe`: installer for Windows 10/11 (recommended)
- `Marky_<version>_x64_en-US.msi`: for managed (IT) deployment

The installers aren't code-signed yet, so Windows SmartScreen shows a warning: choose *More info → Run anyway*.

Installed copies update themselves from this page. Each update is checked against Marky's signing key before it is installed. The source code is kept in a separate, private repository.
