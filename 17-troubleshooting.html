17. Troubleshooting

Problem What to do
Windows warns about the installer Expected until the installer is signed: More info → Run anyway
Desktop: "Access denied: Marky can only use files and folders you opened" Marky only touches files you opened yourself, as a protection against harmful documents. Open the file or its folder again (Ctrl+O, Ctrl+Shift+O)
Web: I can't save into the folder Only Chrome and Edge can write to a folder; other browsers open a read-only copy and download what you save
Pictures from the web don't show Settings › Preview › Load images from the internet has been switched off (it's on by default); switch it on to show them
A very large note (several MB) feels slower The preview waits until you pause typing; everything else stays quick. Notes up to 10 MB are supported
Something odd after installing a plugin Restart in safe mode, then remove the plugin in Manage plugins…
The plugin market says the list isn't signed The list was changed on the way. Nothing is shown or installed; try later
A comment is under Detached The text it was on was changed or deleted. Read it, then resolve or delete it
"That shared note isn't available any more" Sharing was ended, or nobody changed it for 30 days. Ask for a new link
Live · reconnecting… The connection dropped. Keep typing; Marky reconnects and everything merges
"This browser can't do the encryption live editing needs" Use a recent Chrome, Edge, Firefox or Safari 17+, or the desktop app
"That passphrase doesn't open …" Passphrases are case-sensitive; check Caps Lock. Without the right passphrase nobody can open the note
A chart "only reads data from the open folder" Charts don't load data from the internet. Put the data file in the folder and use its name: "url": "data.csv"
Citations show as [@key] The note needs bibliography: file.bib in its properties, the file must be in the folder, and the key must be in it
A video is only a link in an export Exports can't play videos, so they link to them
Desktop: "Codex isn't installed" / "Gemini CLI isn't installed" Install it and sign in once in a terminal, or pick another agent in Settings › Features
Reporting a bug About Marky → Copy diagnostic report (versions and settings, never your notes) and include it
